## 🚀 GUIDE DE DÉMARRAGE RAPIDE

### ⚡ OPTION LA PLUS RAPIDE : Vercel

1. **Téléchargez tous les fichiers** de ce dossier sur votre ordinateur

2. **Allez sur** [vercel.com](https://vercel.com)

3. **Cliquez sur "Add New Project"**

4. **Glissez-déposez** le dossier `kenge14-app` complet

5. **Cliquez sur "Deploy"**

6. ✅ **TERMINÉ !** Votre app est en ligne en 30 secondes !

---

### 📱 GitHub Pages (Gratuit à vie)

1. **Créez un compte** sur [github.com](https://github.com) si vous n'en avez pas

2. **Créez un nouveau repo** nommé `kenge14`

3. **Uploadez tous les fichiers** de ce dossier dans le repo

4. **Allez dans Settings → Pages**

5. **Sélectionnez** "main" branch → Save

6. ✅ **Attendez 2 minutes** → Votre URL sera : `https://VOTRE-NOM.github.io/kenge14/`

---

### 🧪 Test local (avant de déployer)

**Windows :**
1. Ouvrez le dossier `kenge14-app`
2. Double-cliquez sur `index.html`
3. L'app s'ouvre dans votre navigateur

**Mac/Linux :**
```bash
cd kenge14-app
python3 -m http.server 8000
# Ouvrez http://localhost:8000
```

---

### ❓ Besoin d'aide ?

- **Vercel ne marche pas** : Vérifiez que tous les fichiers sont dans le même dossier
- **GitHub Pages ne marche pas** : Attendez 5 minutes, puis rafraîchissez
- **L'app ne charge pas** : Ouvrez la console (F12) et envoyez-moi les erreurs
